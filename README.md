# Baan Chong Cafe - Sales Analytics Dashboard (2568-2569)

แดชบอร์ดวิเคราะห์ยอดขายจำลองของร้าน **Baan Chong Cafe** ทั้ง 4 สาขา (อารีย์, เอกมัย, พระราม 9, และบางแค) ครอบคลุมช่วงปี พ.ศ. 2568 ถึง 2569 

พัฒนาด้วยการออกแบบที่ทันสมัย มีระบบกริดที่ชัดเจน สบายตา มีลูกเล่น Ambient Glow สีสันสวยงาม และระบบคัดกรองข้อมูลอัจฉริยะ (ตามหลักการออกแบบ Dashboard ที่ดี)

---

## 🌟 ฟีเจอร์หลัก (Key Features)

- **KPI Cards สรุปข้อมูลสำคัญ**: แสดงยอดขายรวม, ยอดขายเฉลี่ยต่อเดือน, สาขาที่ทำยอดขายได้ดีที่สุด และระบบคาดการณ์ยอดขายในเดือนถัดไป (Forecast)
- **ระบบกรองข้อมูล (Dynamic Filters)**:
  - เลือกดูรายสาขา หรือดูภาพรวมทุกสาขาได้
  - เลือกช่วงเวลาที่ต้องการดูรายละเอียดได้แบบยืดหยุ่น (ตั้งแต่/ถึง เดือนที่กำหนด)
- **ปุ่มคัดกรองด่วน (Preset Shortcuts)**: สลับดูช่วงเวลาเร่งด่วน เช่น *ทั้งหมด, ปี 2568, ครึ่งปีแรก (H1), ครึ่งปีหลัง (H2), หรือ ปี 2569* ได้ในคลิกเดียว
- **กราฟข้อมูลเชิงลึก (Data Visualizations)**:
  - **กราฟเส้น (Line Chart)**: แสดงแนวโน้มการเติบโตของยอดขายรวมรายเดือน
  - **กราฟวงกลม/โดนัท (Doughnut Chart)**: แสดงสัดส่วนส่วนแบ่งยอดขายของแต่ละสาขา
  - **กราฟแท่ง (Bar Chart)**: เปรียบเทียบผลการดำเนินงานของแต่ละสาขาตามช่วงเวลาที่เลือก

## 🚀 วิธีการติดตั้งและรันระบบ (Setup & Running)

### 1. ติดตั้งไลบรารีที่จำเป็น (สำหรับ Python)
หากคุณต้องการดึงข้อมูลใหม่จากไฟล์ Excel จำเป็นต้องติดตั้งไลบรารี `pandas` และ `openpyxl`:
```bash
pip install pandas openpyxl
```

### 2. อัปเดตข้อมูลยอดขาย (เมื่อมีการแก้ไขไฟล์ Excel)
รันสคริปต์ Python เพื่อดึงข้อมูลจากไฟล์ Excel แปลงเป็นไฟล์ `data.json`:
```bash
python sales_dashboard/extract_data.py
```

### 3. รันเว็บเซิร์ฟเวอร์สำหรับทดสอบในเครื่อง (Local Server)
รันคำสั่งเพื่อจำลองการทำงานบนพอร์ต `8000`:
```bash
python sales_dashboard/run.py
```
เมื่อรันเสร็จแล้ว คุณสามารถเข้าใช้งานแดชบอร์ดได้ผ่านเว็บเบราว์เซอร์ที่ลิงก์:
👉 **[http://localhost:8000](http://localhost:8000)**

## 🎨 แนวคิดการออกแบบแดชบอร์ด (Design System)
แดชบอร์ดนี้พัฒนาขึ้นโดยคำนึงถึงประสบการณ์ของผู้ใช้เป็นหลักตามคู่มือการออกแบบที่ดี:
- **Less is More**: ไม่เน้นสีสันสะท้อนแสงหรือกราฟฟิกที่รกสายตา เพื่อให้ตัวเลขข้อมูลโดดเด่นที่สุด
- **Logical Grouping**: จัดกลุ่ม KPI ไว้อยู่ด้านบน และวางตำแหน่งกราฟวิเคราะห์ด้านล่างเป็นระเบียบตามระบบ Grid
- **White Space**: มีการจัดพื้นที่ว่างขอบข้างรอบๆ เพื่อความสบายตาในการอ่านข้อมูลในระยะยาว
